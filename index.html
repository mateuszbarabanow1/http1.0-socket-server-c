Progetto di Reti di Calcolatori - Mateusz Barabanow

Benvenuto nel server web HTTP/1.0 concorrente implementato in linguaggio C con le Socket API POSIX e la libreria pthread.

Caratteristiche principali del progetto:

  • Architettura multithreaded con un thread dedicato per ogni connessione
  • Gestione sicura delle richieste GET con parsing thread-safe
  • Protezione contro directory traversal e invio parziale dei dati
  • Pagine HTML minimali servite dalla directory locale del server

Il server e' in ascolto sulla porta 8080 e utilizza il protocollo HTTP/1.0.
